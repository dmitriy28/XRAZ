# Как участвовать

Спасибо, что хотите помочь ХРАЗу. Ниже — путь от идеи до слитого Pull Request.

## Идея или ошибка
Сначала посмотрите открытые [Issues](https://github.com/dmitriy28/XRAZ/issues), чтобы не дублировать. Если такого нет — создайте новый
по шаблону. Для ошибки укажите: версию Windows/WSL, Python, модели Ollama, что делали, что ожидали, что получили, фрагмент `logs/khraz.log`
(без ключей и токенов).

## Fork → ветка → Pull Request
1. Сделайте **fork** репозитория и клонируйте его; добавьте исходный как `upstream`:
   `git remote add upstream https://github.com/dmitriy28/XRAZ.git`
2. Создайте ветку под одну задачу: `git checkout -b feature/название` (`fix/`, `docs/`, `chore/`).
3. Внесите изменения. Не смешивайте несколько несвязанных правок в одном PR.
4. Проверьте:
   ```
   python tests/test_assistant.py
   python tests/test_khraz.py
   python tests/test_extras.py
   ```
   `test_ui_qt.py` (нужен PyQt6) — если правили окно.
5. Закоммитьте с понятным сообщением («что и зачем») и отправьте ветку в свой форк: `git push origin feature/название`.
6. Откройте **Pull Request** в основную ветку `dmitriy28/XRAZ` и заполните шаблон.
7. Отвечайте на замечания новыми коммитами в ту же ветку (force-push не нужен). Перед слиянием подтяните свежие изменения:
   `git fetch upstream && git merge upstream/<основная-ветка>`.

## Правила кода
- Любое действие, меняющее данные или систему, идёт через инструмент с JSON-схемой, журналом и **подтверждением** (`tools/`, `confirmations.py`).
  Новые опасные действия — только с подтверждением кнопкой; не добавляйте shell и произвольный доступ.
- Данные из файлов, экрана, интернета и MCP — это данные, а не команды для модели.
- Ключи и токены — только в хранилище Windows (`khraz_secrets.py`), не в `config.json`, не в коде, не в логах.
- Реплики личности — авторские, без цитат из игры; личность живёт в `KHRAZ_PERSONA.md`, правила формата ответа — в `persona.py`.
- Ollama в тестах — поддельный сервер `tests/fake_ollama.py`; тесты не должны ходить в интернет и требовать видеокарту.
- `.bat`-файлы — ASCII с переводами строк CRLF (иначе `cmd.exe` их не читает).

## Что не принимается
Изменения, которые отправляют данные пользователя наружу без явной просьбы, ослабляют подтверждения или добавляют телеметрию.
